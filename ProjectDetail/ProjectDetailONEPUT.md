## 5. Project overview
ออกแบบและพัฒนาส่วนติดต่อประสานงานผู้ใช้ (Web User Interface) ให้กับบริษัท วันพุท เทคโนโลยี จำกัด (ONEPUT Technology Company Limited) มุ่งเน้นการสร้างประสบการณ์ผู้ใช้ที่มีคุณภาพ (User Experience), การจัดวางลำดับองค์ประกอบทางสายตา (Visual Hierarchy), และการพัฒนาเว็บไซต์ที่รองรับทุกขนาดหน้าจอ (Responsive Web Design) 

### ขอบเขตและหน้าที่สำคัญ:
- วิเคราะห์ความต้องการของธุรกิจ (Business Requirements) และแปลงออกมาเป็นโครงสร้างหน้าเว็บที่ตอบโจทย์ผู้ใช้งาน
- ออกแบบ User Flows, Wireframes และ Mockups สำหรับฟีเจอร์และหน้าเว็บใหม่ ๆ
- นำหลักการ Human-Centered Design มาปรับปรุงความสะดวกในการนำทาง (Navigation Flow) และความสามารถในการใช้งาน (Usability)
- ประสานงานและส่งต่องานออกแบบ (Design Handoff) ให้กับทีมนักพัฒนาเพื่อให้งานพัฒนาออกมาตรงตามที่ออกแบบไว้มากที่สุด

## 6. My Role
- **บทบาท:** Web Designer

### ความรับผิดชอบหลัก (Responsibilities & Contributions):
- **User Interface Design:** ออกแบบหน้าเว็บด้วย Figma โดยยึดมาตรฐานความสวยงาม ทันสมัย และความง่ายในการใช้งาน

- **Responsive Layouts:** ออกแบบให้แสดงผลได้อย่างสมบูรณ์บนทุกอุปกรณ์ (Desktop, Laptop, Tablet, Mobile)
- **Collaboration & Implementation:** ทำงานร่วมกับนักพัฒนาในการตรวจสอบความถูกต้องของหน้าเว็บจริง (Design QA)

## 7. Key learnings
1. **การทำงานในสภาพแวดล้อมธุรกิจจริง (Real-world Corporate Environment):**  
   ได้เรียนรู้การทำงานตามเป้าหมายขององค์กร เข้าใจความต้องการของธุรกิจ และจัดการข้อจำกัดทางเทคนิคในการพัฒนาเว็บ
2. **การวางระบบ Design System เพื่อการพัฒนาที่ยั่งยืน (Scalable Design System):**  
   เข้าใจความสำคัญของการสร้าง Components ที่สามารถนำกลับมาใช้ใหม่ได้ (Reusable Components) ซึ่งช่วยประหยัดเวลาของทั้งทีมดีไซน์และทีมพัฒนา
3. **การสื่อสารและส่งต่องาน (Cross-functional Handoff):**  
   พัฒนาทักษะการส่งมอบงานสเปกดีไซน์ให้นักพัฒนาอย่างละเอียด ชัดเจน และตรงไปตรงมา ลดข้อผิดพลาดในการนำโค้ดไปประกอบจริง
