## 5. Project overview
เว็บแอปพลิเคชันเพื่อแก้ปัญหาสภาพแวดล้อมและประสบการณ์การเรียนรู้ในห้องเรียนมหาวิทยาลัย (กรณีศึกษา: อาคารเรียนรวม CB2 มจธ.) ภายใต้คำถามวิจัยหลัก *"สภาพแวดล้อมในห้องเรียนส่งผลต่อคุณภาพการเรียนหรือไม่?"* เพื่อสร้างโซลูชันที่ช่วยให้นักศึกษานั่งเรียนได้อย่างสบายใจและเข้าใจเนื้อหาได้อย่างเต็มประสิทธิภาพ ไม่ว่าจะนั่งตำแหน่งใดในห้องเรียน

### ปัญหาที่พบจากการวิจัย (Key Insights):
- **กลุ่มนั่งหลังห้อง:** เลือกนั่งหลังห้องเพราะต้องการ "Safe Zone" หลีกเลี่ยงความกดดันและการถูกจับจ้องจากอาจารย์ แต่มีอุปสรรคมองสไลด์ไม่ชัดและหลุดโฟกัสง่าย
- **กลุ่มนั่งหน้าห้อง:** นั่งหน้าห้องเพื่อให้เห็นสไลด์ชัดเจน แต่ต้องเผชิญความกดดันและมักหงุดหงิดกับเสียงคุยรบกวนของกลุ่มหลังห้อง

### ฟีเจอร์หลักของ Focus Room:
1. **AI Chatbot สรุปเนื้อหาและสร้างแบบทดสอบ:** สรุปบทเรียนจากไฟล์ PDF และสร้างแบบทดสอบ (Generate Quiz) วัดความเข้าใจ
2. **ระบบแจ้งเตือนเพื่อนที่คุยเสียงดังแบบไม่ระบุตัวตน (Anonymous Noise Reporting):** ส่งข้อความเตือนไปยังหน้าจอเพื่อนโดยไม่เปิดเผยตัวตน พร้อมระบบสอบถามติดตามผลหลัง 5 นาที
3. **ระบบส่งคำถามและ Feedback ให้อาจารย์แบบไม่ระบุตัวตน (Anonymous Feedback):** ช่วยให้นักศึกษากล้าถามข้อสงสัยในคาบเรียนแบบ Real-time โดยไม่รู้สึกประหม่า

### ผลการทดสอบ Usability Testing:
- Task เปิดไฟล์เรียน: Success Rate 100% (เวลาเฉลี่ย 58.3 วินาที)
- Task เตือนเพื่อนเสียงดัง: Success Rate 100% (เวลาเฉลี่ย 24.2 วินาที)
- Task Generate Quiz: Success Rate 80% (เวลาเฉลี่ย 41 วินาที)

## 6. My Role
- **บทบาท:** UX/UI Designer

### ความรับผิดชอบหลัก (Responsibilities & Contributions):
- **User Journey Mapping:** พัฒนา User Journey Map 5 ขั้นตอน (Arrival -> Information Check -> Navigation -> Settling In -> In-Class Experience)

## 7. Key learnings
1. **กระบวนการ User-Centered Design (UCD) อย่างเต็มรูปแบบ:**  
   ได้ลงมือทำตั้งแต่ขั้น Empathize, Define, Ideate, Prototype ไปจนถึง Testing เข้าใจว่าการตัดสินใจออกแบบต้องมี User Insight และ Data รองรับเสมอ
2. **การแก้ปัญหาเชิงจิตวิทยาและสังคมด้วยงานออกแบบ (Social Experience Design):**  
   เรียนรู้วิธีคลี่คลายความขัดแย้งในห้องเรียนด้วยการใช้ระบบ *Anonymous Interaction* และการเลือกใช้สีเหลืองสำหรับการเตือนแทนสีแดง เพื่อลดความรู้สึกคุกคาม
3. **การตีความข้อมูล Usability Metrics:**  
   เข้าใจว่า Success Rate 100% ไม่ได้แปลว่า UI ใช้งานง่ายเสมอไป หากมี Misclick Rate สูง แสดงว่า Visual Affordance ยังไม่ชัดเจนพอ ซึ่งต้องนำข้อมูลมาปรับปรุงแบบ Iterative Design
